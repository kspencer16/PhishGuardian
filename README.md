# PhishDetection
This website will give users the option to input a link, which the website will then process to see if the link is reliable or a phishing scam.

With the use of HTML, CSS, JS, and Python, the website should have a functioning input box that takes the provided website and runs a scan to see if it is malicious and trying to steal information that attackers try to get. 

This will help decrease the amount of scams that unaware users fall for.
